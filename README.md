- ✅ Database (Complete): 5 tables, keys, indexes, view, trigger
- ✅ Frontend (Complete): 6 pages, dark forensic dashboard
- 🟡 OS Part (Partial): Process collector (full) + File collector (working) + Network (stub)

## Tech Stack

Python · Flask (Phase 2) · MySQL · HTML · CSS · JavaScript

## Setup

1. Run `database/schema.sql` in MySQL
2. Run `database/seed.sql`
3. `pip install -r os_modules/requirements.txt`
4. Run `python os_modules/process_collector.py`
5. Run `python os_modules/file_collector.py`
6. Open `frontend/index.html` via local server
